# Text-Difficulty-Predictor
# 📚 Text Difficulty Predictor Using NLP

## 📌 Project Description

**Text Difficulty Predictor** is a Natural Language Processing (NLP) application that analyzes a given text and predicts its difficulty level.

The application classifies text into three categories:

* 🟢 **Easy**
* 🟡 **Medium**
* 🔴 **Difficult**

It analyzes different features of the text, such as word count, sentence count, average word length, long words, and readability score.

---

## 🎯 Objective

The main objective of this project is to develop an application that can automatically determine how easy or difficult a piece of text is to read.

This can be useful for:

* Students
* Teachers
* E-learning platforms
* Reading applications
* Educational websites
* Content creators

---

## 🔄 Working Process

```text
User enters text
       ↓
Text preprocessing
       ↓
Count words and sentences
       ↓
Calculate average word length
       ↓
Detect long words
       ↓
Calculate readability score
       ↓
Calculate difficulty score
       ↓
Predict difficulty
       ↓
Easy / Medium / Difficult
